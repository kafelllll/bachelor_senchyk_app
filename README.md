# Plantch
## Назва та тема роботи
- **Назва проєкту:** plantmatch-app
- **Тема роботи:** «Розроблення веб-платформи для онлайн-обміну рослинами з функцією автоматичного підбору користувачів».

## Короткий опис проекту
Це frontend частина для MVP вебплатформи обміну рослинами. Користувач може зареєструватись, створювати та редагувати оголошення, завантажувати фото рослин, знаходити релевантні пропозиції, спілкуватися з іншими користувачами та керувати профілем.

## Технологічний стек
- `React + TypeScript`
- `Vite`
- `React Router`
- `Tailwind CSS`
- `Socket.IO Client`
- `Vitest + React Testing Library`

# Інструкція зі встановлення та запуску
### 1. Вимоги
- Встановлений `Node.js` (рекомендовано версія 20+)
- Встановлений `npm`
- Запущений backend API (за замовчуванням `http://localhost:3000`)

### 2. Клонування репозиторію
```bash
git clone <URL_репозиторію>
cd plantmatch-app
```

### 3. Встановлення залежностей
```bash
npm install
```

### 4. Налаштування `.env`
Для зручного розгортання додано шаблон `/.env.example`.
Рекомендований порядок:
1. Скопіювати `.env.example` у `.env`.
2. За потреби змінити тільки URL backend.

```bash
cp .env.example .env
```

Для PowerShell:
```powershell
Copy-Item .env.example .env
```

### 5. Запуск у режимі розробки
```bash
npm run dev
```

Після запуску відкрийте адресу, яку покаже Vite у консолі.

### 6. Production build
```bash
npm run build
```

### 7. Перегляд production-версії локально
```bash
npm run preview
```

## 8. Запуск frontend-тестів
```bash
npm run test:frontend
npm run test:frontend:coverage
```

Для коректного відтворення функціоналу:
1. Спочатку запустіть backend.
2. Перевірте коректність `VITE_API_BASE_URL` у `.env`.
3. Запустіть frontend командою `npm run dev`.
